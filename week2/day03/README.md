# Week 2 Day 3 — AI Security Intelligence Engine

## Objective

Use Python dictionaries for dynamic counting,
grouping, lookup tables, aggregation, and basic
security correlation.

## Project

AI Security Intelligence Engine v1.

## Capabilities

- Count security decisions
- Count attack categories
- Count users
- Count severity levels
- Aggregate risk by user
- Aggregate risk by category
- Group events by user
- Group events by category
- Validate required fields

## Core Concepts

- Dynamic dictionary keys
- .get()
- .setdefault()
- Lookup tables
- Frequency analysis
- Aggregation
- Grouping
- Nested structures

## Security Lessons

- Frequency is not the same as severity.
- Aggregate scores require context.
- Unknown data should not automatically become safe data.
- Data integrity affects security conclusions.
- Security telemetry becomes more useful when events can
  be grouped and correlated.

## Limitations

The scoring model and dataset are intentionally simple
learning examples and should not be used as a production
risk-scoring methodology.

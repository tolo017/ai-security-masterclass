# Week 2 Day 2 — Structured Security Records

## Objective

Learn Python dictionaries and use them to model
structured AI security findings.

## Concepts

- keys and values
- dictionary lookup
- mutation
- .get()
- .items()
- nested dictionaries
- lists of dictionaries
- filtering structured records
- basic aggregation

## Project

AI Security Finding Registry.

## Record Structure

Each finding contains:

- finding_id
- user
- prompt
- category
- risk_score
- severity
- decision
- reason

## Security Lessons

- A dictionary represents a structured record.
- A list can represent a collection of records.
- Security data should be modeled explicitly.
- Missing and malformed fields must be considered.
- Data integrity directly affects security conclusions.

## Limitations

The dataset is synthetic and the analysis logic
is intentionally simple.

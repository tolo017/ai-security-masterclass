# Week 2 Day 1 — Security Dataset Fundamentals

## Objective

Learn Python lists, indexing, slicing, mutation,
iteration, searching, filtering, and sorting.

## Project

Prompt Security Dataset v1.

## Capabilities

- Store multiple prompts
- Iterate through prompts
- Filter suspicious candidates
- Count security indicators
- Find highest-risk values
- Extract subsets of data
- Generate basic security statistics

## Key Security Lessons

- Security tooling operates on collections of data.
- Data structures influence reliability.
- Parallel lists can become difficult to maintain.
- External/test data should contain meaningful variation.
- Structured data still requires validation.

## Limitations

This dataset and detection logic are intentionally
simple learning exercises.

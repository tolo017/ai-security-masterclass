# Week 1 Day 1 — Python Security Foundations

## Objective

Learn Python variables, data types, strings, input,
basic calculations, and program state.

## Project

AI Security Input Analyzer.

## What It Does

- Accepts user input
- Normalizes the prompt
- Calculates prompt length
- Detects basic security indicators
- Calculates a basic risk score

## Security Lesson

Deterministic controls can inspect and classify
inputs before they reach an AI model.

## Limitations

This is a learning prototype, not a production
prompt-injection defense.

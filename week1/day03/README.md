## Project

Batch Prompt Security Scanner.

## Capabilities

- Processes multiple prompts
- Detects basic indicators
- Calculates risk scores
- Classifies requests
- Counts security outcomes
- Tracks highest risk
- Calculates block rate

## Security Lesson

Automation allows deterministic security
controls to be applied consistently across
large numbers of events.

## Limitations

The detection logic is intentionally simple
and is not a production AI security defense.
